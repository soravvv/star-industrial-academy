LIVE-ENVIRONMENT LIMITATION
The supplied API is a localhost-only test receiver and no production endpoint was
provided. The hosted site therefore runs in local confirmation mode: it validates
in the browser, shows a notice that details are not sent anywhere, and makes no
network request on submit. To connect a real backend, set VITE_REGISTRATION_API_URL
to an approved HTTPS endpoint in Vercel and redeploy (see README).
